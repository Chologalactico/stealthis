# Feature Flag Panel

The screen every platform team ends up building. Flags live in one plain array; each flag holds independent `{ enabled, rollout }` state per environment. The UI diffs the working copy against a baseline, so the **save bar only appears when something actually changed**, shows an exact change count, and Discard restores the baseline.

## Features

- **Environment tabs** — dev / staging / production, each with its own toggle + rollout state and an "enabled count" badge
- **Percentage rollout** — a slider appears for enabled flags; 100% reads as "everyone", anything less shows the cohort size
- **Dirty-state save bar** — slides up only when the working copy differs from the baseline; Save commits, Discard reverts
- **Search + tag filter** — narrow long flag lists by name, key or tag chip
- **Kill switch** — "Pause all" disables every flag in the current environment in one click (still requires Save, so it's reversible)
- **Production guard** — enabling a flag in prod asks for confirmation inline, no modal needed

## The state shape

```js
{
  key: "new-checkout",
  name: "New checkout flow",
  tags: ["payments"],
  env: {
    dev:     { enabled: true,  rollout: 100 },
    staging: { enabled: true,  rollout: 50 },
    prod:    { enabled: false, rollout: 0 },
  },
}
```
