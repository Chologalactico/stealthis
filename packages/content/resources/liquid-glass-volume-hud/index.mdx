# Liquid Glass Volume HUD

Transient feedback done the iOS way: the HUD has **three sizes and two clocks**. While you're adjusting it stays expanded; one second of stillness slims it to a sliver; another second and it's gone. Every new press resets both timers, so the overlay always feels attentive but never lingers.

## Features

- **Three-state lifecycle** — expanded (adjusting) → slim (1s idle) → hidden (2s idle), driven by two reset-on-input timers
- **Hardware rocker** — on-screen +/− buttons with press squish, plus `↑`/`↓` arrow keys; hold-to-repeat on both
- **Level-aware icon** — 🔇 at zero, then 🔈 → 🔉 → 🔊 as the level climbs; the fill snaps in 6% steps like real volume ticks
- **Brightness mode** — press `B` (or the toggle) to switch the same HUD to a brightness sun with its own remembered level
- **Direction nudge** — the capsule micro-translates in the press direction, a detail straight from the platform
- **Reduced motion aware** — size morphs become opacity-only transitions

## The two clocks

```js
function poke() {
  hud.dataset.state = "expanded";
  clearTimeout(slimTimer);  clearTimeout(hideTimer);
  slimTimer = setTimeout(() => (hud.dataset.state = "slim"), 1000);
  hideTimer = setTimeout(() => (hud.dataset.state = "hidden"), 2200);
}
```
