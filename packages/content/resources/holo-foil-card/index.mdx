# Holographic Foil Trading Card

A collectible-grade **holo foil card** rendered entirely in the browser. The card face is painted onto a `CanvasTexture` (frame, emblem, title, stats — no image assets), then a custom `ShaderMaterial` layers the holographic treatment on top: diagonal rainbow interference bands whose phase is driven by the card's tilt, a hash-noise sparkle field that glints as the angle changes, and a soft fresnel edge shine.

## Highlights

- **Custom GLSL foil** — rainbow bands + sparkle glints react to `uTilt`, exactly like rotating a real foil card under light
- **Zero image assets** — the card art (frame, prism emblem, typography, stat bars) is drawn with the 2D canvas API
- **Pointer tilt** — lerped rotation targets for weighty, physical motion; the foil phase shifts with the tilt
- **Click to flip** — GSAP flips the card to a procedurally drawn back design
- **Rounded corners in-shader** — an SDF rounded-rect alpha mask keeps the silhouette crisp at any resolution
- **Reduced motion aware** — tilt and idle float are disabled under `prefers-reduced-motion`
