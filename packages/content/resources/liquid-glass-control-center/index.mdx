# Liquid Glass Control Center

The Control Center grid, rebuilt as web components on the Liquid Glass material. Each tile is an independent glass sandwich (effect → tint → shine → content), so tiles can be rearranged or dropped into any layout without coupling.

## Features

- **Connectivity cluster** — airplane, Wi-Fi, Bluetooth and cellular as round toggles inside one shared tile; active state fills the disc with the accent color
- **Vertical drag sliders** — brightness and volume tiles fill from the bottom under pointer drag (with pointer capture), exactly like the iOS gesture, and report their value
- **Focus toggle & utility row** — a wide focus switch plus flashlight, timer, calculator and camera buttons with pressed states
- **Composable tiles** — every tile carries its own glass layers; the grid is plain CSS Grid
- **Reduced motion aware** — ambient background drift and press springs are disabled under `prefers-reduced-motion`

## Vertical slider gesture

```js
tile.addEventListener("pointerdown", (e) => {
  tile.setPointerCapture(e.pointerId);
  const rect = tile.getBoundingClientRect();
  const set = (ev) => {
    const ratio = 1 - (ev.clientY - rect.top) / rect.height;
    fill.style.height = `${Math.min(Math.max(ratio, 0), 1) * 100}%`;
  };
  set(e);
  tile.onpointermove = (ev) => tile.hasPointerCapture(ev.pointerId) && set(ev);
});
```
