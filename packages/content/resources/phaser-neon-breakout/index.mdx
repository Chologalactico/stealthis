# Phaser Neon Breakout

A full game loop in one file: **Phaser 3** arcade physics, a 5×10 neon brick wall, pointer and keyboard control, score, lives, win and game-over states. The interesting trick is asset generation — there are no sprites to load. Each texture (paddle, ball, five brick colors) is drawn once into a `Graphics` object and baked with `generateTexture`, so the game boots instantly with nothing to download.

## Highlights

- **Zero-asset pipeline** — `Graphics.fillRoundedRect` → `generateTexture` replaces the entire sprite sheet
- **Angle control** — the ball's exit angle depends on where it strikes the paddle, the classic skill mechanic
- **Escalating pace** — every brick nudges ball speed up toward a cap, so clears get tense
- **Open floor** — world bounds collide on three sides only; the bottom is a life lost
- **Full loop** — launch → play → lose lives → game over → click to restart, plus a win state
- **Reduced motion aware** — camera shake is skipped under `prefers-reduced-motion`
