# Role Permission Matrix

RBAC configuration lives or dies on scanability. This matrix keeps permissions **grouped by area** (Content, Members, Billing, Settings), puts roles in sticky columns, and makes bulk edits cheap: click a role's header toggle to grant or clear the whole column, or a row's quick-toggle to flip that permission across all editable roles at once.

## Features

- **Grouped rows** — area headers break the permission list into scannable chunks
- **Bulk toggles** — per-role column toggle ("grant all to Editor") and per-permission row toggle ("everyone can view invoices")
- **Locked Owner** — the Owner column is always fully granted and visibly non-editable, the way real RBAC systems guard the root role
- **Dirty diffing** — the working matrix is compared to a baseline; the save bar appears only with real changes and shows an exact count
- **Change summary** — saving reports how many grants were added and removed
- **Accessible** — a real `<table>` with row/column headers, real checkboxes, and full keyboard operability

## State shape

```js
matrix["posts.delete"]["editor"] = false;
// diff vs baseline drives the save bar; Save commits, Discard reverts
```
