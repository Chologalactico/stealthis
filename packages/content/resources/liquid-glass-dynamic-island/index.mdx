# Liquid Glass Dynamic Island

The Island is a state machine wearing a spring. Each state (idle, music chip, music expanded, timer) is just a CSS class that sets `width`/`height`/`border-radius`; a single overshoot cubic-bezier on those properties produces the characteristic gooey morph, and content panels crossfade with a slight scale so the interior feels attached to the shell.

## Features

- **Four morph states** — idle capsule → compact music chip → expanded player card → timer chip, all one element
- **Live activity content** — the music state runs animated EQ bars and track info; the timer state runs a real countdown with an SVG progress ring
- **Tap to expand** — the compact music chip opens into a full card with controls; tapping the header collapses it back
- **Overshoot spring** — one `cubic-bezier(0.34, 1.4, 0.4, 1)` transition on the shell does all the gooey work
- **Demo triggers** — buttons start/stop each activity the way apps would post Live Activities
- **Reduced motion aware** — morphs become instant resizes and the EQ bars hold a static pose

## The morph

```css
.island {
  transition:
    width 0.55s cubic-bezier(0.34, 1.4, 0.4, 1),
    height 0.55s cubic-bezier(0.34, 1.4, 0.4, 1),
    border-radius 0.55s cubic-bezier(0.34, 1.4, 0.4, 1);
}
.island.state-music-chip { width: 260px; height: 40px; }
.island.state-music-full { width: 340px; height: 150px; border-radius: 34px; }
```
