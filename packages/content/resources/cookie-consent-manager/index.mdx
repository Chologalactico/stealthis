# Cookie Consent Manager

Consent UIs get bolted on last and it shows. This one is built as a small self-contained module: state lives in one versioned `localStorage` key, every save dispatches a `consentchange` CustomEvent so analytics and marketing scripts can subscribe, and the demo page includes a live integration monitor that lights up as you change categories.

## Features

- **Three-path banner** — Accept all / Necessary only / Customize, with equal visual weight (dark-pattern-free)
- **Preferences dialog** — a native `<dialog>` with per-category toggles and descriptions; the necessary category is visibly locked on
- **Versioned persistence** — the storage key carries a version, so bumping it legally re-prompts every visitor
- **Event-driven integrations** — `window.addEventListener("consentchange", …)` is the only API scripts need
- **Reopen affordance** — after a choice, a floating button lets visitors change their mind anytime (a GDPR requirement)
- **Accessible** — focus moves into the dialog, `Escape` closes it, toggles are real checkboxes with labels

## Integration

```js
window.addEventListener("consentchange", (e) => {
  if (e.detail.analytics) loadAnalytics();
  if (e.detail.marketing) loadPixel();
});
```
