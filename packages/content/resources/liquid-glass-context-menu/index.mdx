# Liquid Glass Context Menu

The interaction has three synchronized parts, and getting all three right is what makes it feel native: the **pressed bubble lifts** (scale + shadow) while everything else blurs and dims, a **reaction bar** pops in above it, and the **menu** springs in below — flipping above automatically when the bubble sits low in the viewport.

## Features

- **Press-and-hold** — a 380ms hold timer with movement cancellation opens the menu; right-click (`contextmenu`) is the desktop shortcut
- **Focus staging** — the thread gets `filter: blur()` + dim while the target bubble scales up out of the fog
- **Reaction bar** — five emoji in a glass capsule; picking one pins a reaction badge onto the bubble (tap the same one to remove it)
- **Smart placement** — the menu measures the bubble's position and opens below or above, staying inside the viewport
- **Destructive styling** — Delete sits apart and reads in red, matching the platform convention
- **Reduced motion aware** — springs become fades; the blur stage-dim still communicates focus

## The hold gesture

```js
bubble.addEventListener("pointerdown", (e) => {
  holdTimer = setTimeout(() => openMenu(bubble), 380);
});
bubble.addEventListener("pointermove", (e) => {
  if (Math.hypot(e.clientX - startX, e.clientY - startY) > 8) clearTimeout(holdTimer);
});
bubble.addEventListener("pointerup", () => clearTimeout(holdTimer));
```
