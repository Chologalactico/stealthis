# DNA Helix Scroll Story

A cinematic scroll experience where a **procedural DNA double helix** reacts to the page. The helix is built from two strands of instanced spheres joined by base-pair rungs, and every geometric property — twist, radius, strand separation, hue — lives in a single params object that a scrubbed GSAP timeline tweens as you scroll.

## Highlights

- **Instanced geometry** — 220 spheres + 27 rungs rendered with two `InstancedMesh` draw calls
- **Scroll choreography** — Sequence → Unwind → Split → Recombine, one scrubbed timeline across four panels
- **Live re-layout** — strand positions are recomputed every frame from tweened params, so the helix genuinely unwinds instead of just rotating
- **Per-instance color** — both strands re-tint through the story via `setColorAt` and HSL lerping
- **Lenis smooth scroll** — synced to the GSAP ticker for buttery scrubbing
- **Reduced motion aware** — falls back to a static, gently lit helix when `prefers-reduced-motion` is set

## Tech Stack

| Layer | Technology |
|-------|-----------|
| 3D | Three.js (InstancedMesh, FogExp2, Points) |
| Scroll | Lenis (CDN) |
| Animation | GSAP + ScrollTrigger (CDN) |
| Styling | CSS custom properties, glass panels |
| Typography | Space Grotesk + Inter |

## How it works

1. `strandPos(i, phase)` maps an index to a point on a helix using the current `params` (twist, radius, separation)
2. A single `gsap.timeline({ scrollTrigger: { scrub: 1 } })` tweens `params` through four labeled chapters
3. The render loop rebuilds instance matrices each frame, so scroll position and idle motion compose naturally
