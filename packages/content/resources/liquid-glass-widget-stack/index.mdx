# Liquid Glass Widget Stack

The home-screen Smart Stack: several widgets share one footprint and rotate through it. The shell (one Liquid Glass sandwich) never moves — only the widget faces do, flipping vertically with a spring. Incoming faces rise from below at 92% scale; outgoing ones lift away and fade, which sells the "pile of cards" illusion in two transforms.

## Features

- **Three demo widgets** — weather (temp, condition, hi/lo), calendar (date + next events with color bars), battery (SVG ring per device)
- **Vertical swipe** — pointer-capture drag with a distance threshold flips forward or back; wraps at the ends
- **Smart-Stack auto-rotate** — advances every 5 seconds, pauses on hover and after any interaction, resumes on leave
- **Page dots** — tappable indicators on the right edge, exactly where iOS puts them
- **Per-widget accent** — each face tints the shell's hue variable so the glass picks up its subject
- **Reduced motion aware** — auto-rotate is off and flips are instant crossfades under `prefers-reduced-motion`

## The flip

```css
.face { transition: transform 0.5s cubic-bezier(0.32, 1.25, 0.4, 1), opacity 0.35s; }
.face.is-active { transform: translateY(0) scale(1); opacity: 1; }
.face.is-below  { transform: translateY(34%) scale(0.92); opacity: 0; }
.face.is-above  { transform: translateY(-34%) scale(0.92); opacity: 0; }
```
