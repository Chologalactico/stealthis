# p5.js Flow Field Painter

The classic of creative coding, tuned for elegance: a **flow field** where each particle samples 3D Perlin noise (`x`, `y`, time) to decide its heading, then drags a low-alpha stroke behind it. Because the canvas is only faintly washed each frame, the trails accumulate into dense, silky filaments — every seed produces a one-of-a-kind composition.

## Highlights

- **3D noise field** — the third noise dimension drifts slowly, so the currents themselves evolve over time
- **Four curated palettes** — Ember, Reef, Ivory (light!) and Neon, each with its own canvas wash color
- **Click to regenerate** — a fresh `noiseSeed` and particle drop; the palette button re-paints the same field in new colors
- **Adaptive density** — particle count scales with viewport area, capped for low-end devices
- **Reduced motion aware** — under `prefers-reduced-motion` the sketch renders 300 steps instantly and presents a finished still artwork

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Sketch | p5.js (global mode) |
| Field | `noise()` — Perlin, 3 dimensions |
| Trails | Low-alpha background wash per frame |
| Typography | DM Mono + Inter |
